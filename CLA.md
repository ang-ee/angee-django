## How to sign

This agreement covers Contributions to **all repositories in the `ang-ee` GitHub
organization**. You sign once.

When you open your first pull request, an automated check will ask you to sign.
Add a comment on the pull request containing exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Your signature — your GitHub username, user ID, pull request number, and the
timestamp — is recorded in a signature register maintained by Angee. Comment
`recheck` on the pull request to re-run the check.
