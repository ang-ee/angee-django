The whole leading cell selects a row, and grouped lists expand, collapse and
select all (`LeadingSelectionCell`, `SelectionToggle`, `ListSelectionBar`); the
resource view keeps one selection owner with row snapshots. An embedded list
is compact by default, and a rows list shows search and pager only once it
outgrows a page (`listChromeState`).
