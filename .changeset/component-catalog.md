`@angee/ui/catalog` publishes the generated component catalog
(`componentCatalog`, `CatalogSchema`, `CatalogEntrySchema`, `parseCatalog`,
`COMPONENT_KINDS`, `REGION_PLACES`) and `@angee/ui/tokens` the token names
(`tokenNames`). Every public export carries one UX kind (token, primitive,
fragment, region, surface, page or contribution); `recipeAxes` reads a recipe's
variant axes.
