# Owner index

Search aliases plus links. The rule that decides a concern lives in the linked
guide, stack row, glossary entry or module docstring; this index only says where
to look. Rows name the owner symbol with its defining `path:line`, the governing
rule, and the applicability condition as that rule or docstring states it.

## How to search

```sh
grep -i "<keyword>" .agents/skills/angee-design/references/owners.md
```

Try the words a feature request uses (`archive`, `position`, `plugin`, `secret`)
and the column names an agent would reach for (`is_deleted`, `created_by`,
`parent`, `external_id`). A hit names the owner to read before writing; a miss
means search two nearby addons and the sibling slots before concluding no owner
exists. `tests/test_owner_index.py` checks the Owner column only: every cell carries
at least one `` `Symbol` path:line `` citation, every `path:line` in a cell is such a
citation, the file exists, and the cited line (or the decorator line directly above
it) declares the symbol; every public class an `angee.base.models`/`angee.base.fields`
module declares is cited at that module, and every `angee.*` addon (by name or a
path in its folder) has a cell. The rule and
applicability columns are not checked. Guides are linked by section anchor with the
line in code text.
