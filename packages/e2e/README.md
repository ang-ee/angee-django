# @angee/e2e

`@angee/e2e` provides the Playwright fixtures, authentication helpers, GraphQL client, and page-object base used by Angee end-to-end suites; it stays outside the runtime package dependency layers and consumes applications only through their public browser surface.

Install: `pnpm add -D @angee/e2e`
